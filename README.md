# Next Level Life

Личное Android-приложение: отвлекающие приложения закрыты, пока экранное время не заработано упражнениями.

Instagram, YouTube, VK, TikTok и браузеры открываются только при положительном балансе минут. Минуты начисляются за повторения, которые считает камера телефона. Мессенджеры и звонки доступны всегда.

> **Состояние: версия 0.3.0, в разработке.** Один APK для Samsung S25 и Z Fold 8. Счёт камерой проверен на человеке для отжиманий и приседаний (15 из 15). Остальное в 0.3 проверено тестами и на эмуляторе, на настоящем телефоне — частично (см. ниже).

## Как это работает

1. Служба специальных возможностей следит, какое приложение открыто.
2. Пока открыто приложение из списка блокировки, баланс минут уменьшается. Расход за день ограничен лимитом, ночью заблокированное не открывается совсем. Заработанный баланс не сгорает.
3. Баланс кончился, лимит исчерпан или наступила ночь — поверх приложения появляется экран с причиной.
4. Ставишь телефон сбоку в 1,5–2 м, делаешь упражнение. Камера считает повторения, голос ведёт счёт.
5. За каждое повторение начисляется экранное время и опыт.

Распознавание позы идёт на телефоне (CameraX + ML Kit). Видео не записывается и никуда не отправляется. Шаги и пробежки только читаются из Health Connect и остаются на телефоне.

## Цены

Цена повторения одна и та же в отдельном подходе и внутри комплекса.

| Упражнение | Секунд за повторение |
|---|---|
| Отжимания | 30 |
| Приседания | 40 |
| Пресс | 35 |
| Подтягивания | 60 |
| Трастер с гирей | 45 |
| Мах гирей | 30 |
| Тяга сумо к подбородку | 30 |
| Тяга в наклоне | 25 |
| Становая тяга | 25 |

Упражнения с гирей оценены для 16 кг. Гиря 24 кг даёт ×1,2, гиря 32 кг — ×1,6.

Ходьба и бег (когда включено): 5 минут за 1000 шагов, 10 минут за километр, вместе не больше 60 минут в день; шаги пробежки второй раз не оплачиваются.

## Комплексы

Проходятся без рук: приложение само объявляет голосом упражнение и число повторений.

- **Минотавр.** Лесенка 10→1 из пяти движений с гирей, 275 повторений на время. Фиксированная награда: 2,5 / 3 / 4 часа за 16 / 24 / 32 кг.
- **Синди.** 5 подтягиваний, 10 отжиманий, 15 приседаний — максимум кругов за 20 минут. Награда по ценам повторений.

## Установка

Сборки лежат в разделе [Releases](../../releases). Только для телефонов на arm64, Android 10 и новее.

1. Скачать APK на телефон и установить (разрешить установку из этого источника).
2. Открыть приложение и включить его службу в «Специальных возможностях».
3. Разрешить камеру.
4. Отключить для приложения экономию батареи, иначе система может остановить службу.
5. Для шагов: в Garmin Connect включить передачу данных в Health Connect, затем в приложении «Настройки» → «Шаги и пробежки» → «Подключить Health Connect».

Сейчас сборки отладочные. Когда появится постоянный ключ подписи, приложение придётся один раз переустановить. Перед этим сделай резервную копию в «Настройках».

## Сборка из исходников

Нужны Android SDK и JDK 17 или новее (подходит JBR из Android Studio).

```bash
./gradlew :app:assembleDebug
```

```bash
./gradlew :app:testDebugUnitTest
```

APK появится в `app/build/outputs/apk/debug/`. Для эмулятора на ПК (x86_64) добавь `-Pemu`.

## Структура кода

`app/src/main/java/com/nextlevellife/app/`

| Папка | Что внутри |
|---|---|
| `block/` | Служба блокировки, правила (баланс, лимит, ночь), список приложений |
| `data/` | Упражнения и цены, журнал баланса, дневник, настройки, резервная копия |
| `health/` | Чтение шагов и пробежек из Health Connect, начисление |
| `pose/` | Камера, распознавание позы, счётчики повторений, звук, запись движений |
| `ui/` | Экраны: тренировка, прогресс, настройки, упражнение, комплекс, блокировка |
