# Next Level Life

Личное Android-приложение: отвлекающие приложения закрыты, пока экранное время не заработано упражнениями.

Instagram, YouTube, VK, TikTok и браузеры открываются только при положительном балансе минут. Минуты начисляются за повторения, которые считает камера телефона. Мессенджеры и звонки доступны всегда.

> **Состояние: версия 0.2.0, в разработке.** Счёт камерой проверен только на синтетических данных. На живом человеке первая версия недосчитывала (3–5 из 15), исправления ещё не проверены.

## Как это работает

1. Служба специальных возможностей следит, какое приложение открыто.
2. Пока открыто приложение из списка блокировки, баланс минут уменьшается.
3. Баланс кончился — поверх приложения появляется экран «заработай минуты».
4. Ставишь телефон сбоку в 1,5–2 м, делаешь упражнение. Камера считает повторения, голос ведёт счёт.
5. За каждое повторение начисляется экранное время и опыт.

Распознавание позы идёт на телефоне (CameraX + ML Kit). Видео не записывается и никуда не отправляется.

## Цены повторений

Цена одна и та же в отдельном подходе и внутри комплекса.

| Упражнение | Секунд за повторение |
|---|---|
| Отжимания | 30 |
| Приседания | 40 |
| Пресс | 35 |
| Подтягивания | 60 |
| Трастер с гирей | 45 |
| Мах гирей | 30 |
| Тяга сумо к подбородку | 30 |
| Тяга в наклоне | 25 |
| Становая тяга | 25 |

Упражнения с гирей оценены для 16 кг. Гиря 24 кг даёт ×1,2, гиря 32 кг — ×1,6.

## Комплексы

Проходятся без рук: приложение само объявляет голосом упражнение и число повторений.

- **Минотавр.** Лесенка 10→1 из пяти движений с гирей, 275 повторений на время. Фиксированная награда: 2,5 / 3 / 4 часа за 16 / 24 / 32 кг.
- **Синди.** 5 подтягиваний, 10 отжиманий, 15 приседаний — максимум кругов за 20 минут. Награда по ценам повторений.

## Что ещё есть

- Уровни, опыт, серия дней подряд, личные рекорды комплексов.
- Дневник тренировок: каждый подход и каждое прохождение комплекса сохраняются по дням (SQLite). Экрана просмотра пока нет.
- Запись движений подхода (координаты суставов, без видео) для подбора порогов счёта.
- Список блокировки по умолчанию: видео, соцсети и браузеры. Меняется на экране «Приложения».

## Установка

Сборки лежат в разделе [Releases](../../releases). Только для телефонов на arm64, Android 10 и новее.

1. Скачать APK на телефон и установить (разрешить установку из этого источника).
2. Открыть приложение и включить его службу в «Специальных возможностях».
3. Разрешить камеру.
4. Отключить для приложения экономию батареи, иначе система может остановить службу.

Сейчас сборки отладочные. Когда появится постоянный ключ подписи, приложение придётся один раз переустановить.

## Сборка из исходников

Нужны Android SDK и JDK 17 или новее (подходит JBR из Android Studio).

```bash
./gradlew :app:assembleDebug
```

```bash
./gradlew :app:testDebugUnitTest
```

APK появится в `app/build/outputs/apk/debug/`.

## Структура кода

`app/src/main/java/com/nextlevellife/app/`

| Папка | Что внутри |
|---|---|
| `block/` | Служба блокировки и список приложений |
| `data/` | Упражнения и цены, баланс, дневник, начисление наград |
| `pose/` | Камера, распознавание позы, счётчики повторений, звук, запись движений |
| `ui/` | Экраны: главная, упражнение, комплекс, блокировка, приложения |

План работ — в [PLAN.md](PLAN.md).
